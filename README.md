# Smart Parking System Using Cisco Packet Tracer

## Project Overview

This project demonstrates a basic IoT-based Smart Parking System developed using Cisco Packet Tracer for our Computer Networks PBL.

The system uses network-connected devices, motion sensors, a smart garage door, and indicator lamps to simulate automated parking management.

## Features

- Automatic parking gate control
- Motion-based vehicle detection
- Smart parking indicator lights
- HTTP web server connectivity
- IoT device management through a Home Gateway
- Network communication testing

## Components Used

- Cisco Packet Tracer
- PC and HTTP Server
- Home Gateway
- Motion Detectors
- Garage Door
- Smart Lamps
- Network Connections

## Working

The parking system uses motion sensors and predefined IoT automation conditions to control the parking gate and indicator lights.

An administrator can also access the configured HTTP server through the PC's web browser to demonstrate network connectivity.

## How to Run

1. Download the `.pkt` file.
2. Open it in Cisco Packet Tracer.
3. Select Realtime mode.
4. Open the server's IP address using PC0's web browser.
5. Activate the motion sensors and observe the configured gate and lamp actions.

## Concepts Used

Computer Networks, IP Addressing, HTTP, IoT Communication, Wireless Networking, and Automation.
